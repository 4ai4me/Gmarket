# 가락시장 단가·수지타산 분석 (Garak Agro-ROI)

- **현재 버전**: `v0.5.0` (단일 원본: `VERSION`)
- **GitHub Pages 주소**: `https://4ai4me.github.io/Gmarket/`

## 1. 프로그램 개요
서울 가락농수산물도매시장(`temp.garak.co.kr`)에 등록된 전체 농산물 품목·포장단위 정보(최근 10년 119개월 전수 크롤링 포함)와 경매결과 엑셀(`.xls`/`.xlsx`/`.csv`) 데이터를 기반으로 다음 분석을 지원하는 웹 도구입니다.

1. **가락시장 최근 10년(2017~2026) 전 품목 크롤링 이력 & 공백월·확대/축소 분석**: 가락시장 공개 경매 엔드포인트(`selectAutoCompleteAjax.do`)에서 2017.01~2026.11 119개월 전수 수집한 **973개 품목(원시 옵션 117,525건)**의 연도별 추세, 1~12월 10년 실측 출현빈도 히트맵, 완전 공백월(예: 달래 6~7월 0/10년, 두릅 11~12월 0/10년), 확대/축소 품목 필터 및 CSV/JSON 내보내기를 제공합니다.
2. **대한민국 지도 출하지별 기간 설정 · 지역별 1~12월 출하 시점 비교 & 타지역 공백기(틈새 수확) 패턴**: 전국 17개 시·도 지도에서 계절 프리셋·`시작월~종료월`(월동 `12~2월` 포함)·엑셀 일자 범위·1~12월 클릭 타임라인으로 기간을 설정하고, **지역별 1~12월 출하 시점 히트맵(시·도/시·군·구)** 및 **타지역 미출하 공백기 틈새 수확 기회 카드(원클릭 지도 전환)**를 확인합니다.
3. **년간 경매 물량 · 5개년 수급 추세 & 내년 가격 리스크 선행 경보**: 올해 고단가에 쏠려 내년 공급과잉으로 단가가 하락하는 &lsquo;거미집 파동&rsquo;을 피하기 위해 품목별 5개년(2022~2026) 연간 반입량(톤)·평균단가 추이, 확대/감소 주산지, 단가 -20% 하락 시나리오 순수익(안전마진 %)을 교차 분석해 **내년 하락 주의 / 공급감소 진입 유망 / 하방안정 고ROI** 신호를 제공합니다.
4. **가락시장 전 품목 × 재배방법 × 1년 수지타산(ROI) · 하방 스트레스 테스트**: 정밀 기준 작목 DB(81종) + 가락 12개월 자동매핑 + 엑셀 실측 품목(130종+)의 1년 ROI를 시뮬레이션하며, **3개년 평균가·-20% 방어가 프리셋** 및 **내년 단가 -15%/-25% 하락 스트레스 테스트·안전마진**을 실시간 계산합니다.
5. **다기간(연도·월별) 가락시장 엑셀 누적 병합 & 시계열 비교**: 여러 연도·월의 OZViewer `Save XLS` 파일을 누적 병합(`localStorage` 자동 저장)해 기간별 총 반입량·단가·품목별 증가/감소 출하지를 자동 비교하며, 2024~2026 다기간 비교 샘플을 원클릭으로 체험할 수 있습니다.

## 2. 실행 및 빌드 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 3000, 실시간 가락시장 프록시 포함)
npm run dev

# 단위 테스트 실행 (단위 환산 · 엑셀 파서 · 다개년 수급/거미집 리스크 · 지역 출하 시점/공백기 · 10년 크롤링 무결성 · ROI 계산)
npm test

# 가락시장 최근 10년치 공개 품목·거래단위 재크롤링 (public/data/garak-10yr-catalog.json 갱신)
npm run crawl:10yr

# 타입 검사 및 프로덕션 정적 빌드 (dist/)
npm run lint
npm run build

# 프로덕션 서버 실행
NODE_ENV=production npm start
```

## 3. GitHub Pages 배포 방법 (`https://4ai4me.github.io/Gmarket/`)

1. 이 프로젝트 전체를 `4ai4me/Gmarket` 저장소의 `main` 브랜치에 푸시합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **`GitHub Actions`**로 변경합니다.
   - 주의: `Deploy from a branch (main / root)`로 설정하면 빌드 전 `src/main.tsx`를 참조하는 원본 `index.html`이 그대로 서빙되어 빈 페이지가 됩니다. 반드시 **`GitHub Actions`**를 선택하세요.
3. `.github/workflows/deploy-pages.yml` 워크플로가 자동으로 `npm run build`를 실행해 상대 경로(`base: './'`)로 빌드된 `dist/`를 `https://4ai4me.github.io/Gmarket/`에 배포합니다.
   - 정적 호스팅(GitHub Pages) 환경에서는 Express 백엔드(`/api/*`) 대신 내장된 가락시장 12개월 통합 실제 스냅샷(660종)과 전국 주산지·5개년 수급 기준 데이터가 자동 로드되며, 엑셀 다기간 누적 분석·대한민국 지도 출하지 시각화·전 품목 1년 수지타산 교차분석이 브라우저에서 100% 정상 동작합니다.
