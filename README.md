# 가락시장 단가·수지타산 분석 (Garak Agro-ROI)

- **현재 버전**: `v0.4.1` (단일 원본: `VERSION`)
- **GitHub Pages 주소**: `https://4ai4me.github.io/Gmarket/`

## 1. 프로그램 개요
서울 가락농수산물도매시장(`temp.garak.co.kr`)에 등록된 전체 농산물 품목·포장단위 정보와 경매결과 엑셀(`.xls`/`.xlsx`/`.csv`) 데이터를 기반으로 다음 분석을 지원하는 웹 도구입니다.

1. **년간 경매 물량 · 5개년 수급 추세 & 내년 가격 리스크 선행 경보**: 올해 고단가에 쏠려 내년 공급과잉으로 단가가 하락하는 &lsquo;거미집 파동&rsquo;을 피하기 위해 품목별 5개년(2022~2026) 연간 반입량(톤)·평균단가 추이, 확대/감소 주산지, 단가 -20% 하락 시나리오 순수익(안전마진 %)을 교차 분석해 **내년 하락 주의 / 공급감소 진입 유망 / 하방안정 고ROI** 신호를 제공합니다.
2. **대한민국 지도 기반 출하지별 경매 현황 & 산지 증감(YoY) 대시보드**: 전국 17개 시·도 인터랙티브 단계구분도(Choropleth) 지도에서 품목·품종·단위·등급별로 출하 중량(kg)·거래 수량·총 경매액·가중평균 kg단가 및 **전년대비 산지 물량 증감(%)**·**상위 2개 시·도 편중도**를 교차 조회하고, 시·군·구 드릴다운 및 엑셀 실측 출하지를 즉시 반영합니다.
3. **가락시장 전 품목 × 재배방법 × 1년 수지타산(ROI) · 하방 스트레스 테스트**: 정밀 기준 작목 DB(81종) + 가락 12개월 자동매핑 + 엑셀 실측 품목(130종+)의 1년 ROI를 시뮬레이션하며, **3개년 평균가·-20% 방어가 프리셋** 및 **내년 단가 -15%/-25% 하락 스트레스 테스트·안전마진**을 실시간 계산합니다.
4. **다기간(연도·월별) 가락시장 엑셀 누적 병합 & 시계열 비교**: 여러 연도·월의 OZViewer `Save XLS` 파일을 누적 병합(`localStorage` 자동 저장)해 기간별 총 반입량·단가·품목별 증가/감소 출하지를 자동 비교하며, 2024~2026 다기간 비교 샘플을 원클릭으로 체험할 수 있습니다.
5. **가락시장 12개월 통합 전 품목 · 거래단위 실시간/스냅샷 조회 & 년·월·주 단가 순위**: 가락시장 `selectAutoCompleteAjax.do`를 최근 12개월 기준으로 통합 수집(약 660종+)하여 `원/kg`·고유 거래단위·`10a` 연 매출 기준 순위와 계절 추이를 비교합니다.

## 2. 실행 및 빌드 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 3000, 실시간 가락시장 프록시 포함)
npm run dev

# 단위 테스트 실행 (단위 환산 · 엑셀 파서 · 다개년 수급/거미집 리스크 · 지역 산지 증감 · ROI 계산)
npm test

# 타입 검사 및 프로덕션 정적 빌드 (dist/)
npm run lint
npm run build

# 프로덕션 서버 실행
NODE_ENV=production npm start
```

## 3. GitHub Pages 배포 방법 (`https://4ai4me.github.io/Gmarket/`)

1. 이 프로젝트 전체를 `4ai4me/Gmarket` 저장소의 `main` 브랜치에 푸시합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **`GitHub Actions`**로 변경합니다.
   - 주의: `Deploy from a branch (main / root)`로 설정하면 빌드 전 `src/main.tsx`를 참조하는 원본 `index.html`이 그대로 서빙되어 빈 페이지가 됩니다. 반드시 **`GitHub Actions`**를 선택하세요.
3. `.github/workflows/deploy-pages.yml` 워크플로가 자동으로 `npm run build`를 실행해 상대 경로(`base: './'`)로 빌드된 `dist/`를 `https://4ai4me.github.io/Gmarket/`에 배포합니다.
   - 정적 호스팅(GitHub Pages) 환경에서는 Express 백엔드(`/api/*`) 대신 내장된 가락시장 12개월 통합 실제 스냅샷(660종)과 전국 주산지·5개년 수급 기준 데이터가 자동 로드되며, 엑셀 다기간 누적 분석·대한민국 지도 출하지 시각화·전 품목 1년 수지타산 교차분석이 브라우저에서 100% 정상 동작합니다.
